# CAT Mock Analyzer

**Install & Run**: Execute `start.sh` (Mac/Linux) or `start.bat` (Windows), or manually run `npm install && npm run dev`.
**Data Location**: All your mocks and settings are saved locally in `data/cat.db`. 
**Backup**: To back up your data, simply copy the `data/cat.db` file to a safe location.
**Theme**: The app defaults to a calm dark mode, optimized for analytics.
**Seed Data**: Run `npm run seed` to insert dummy mocks to view the analytics engine.
